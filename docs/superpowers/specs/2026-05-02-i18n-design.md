# i18n (다국어) 지원 설계

**날짜:** 2026-05-02
**목표:** 안드로이드 기기 언어 설정(또는 앱 내 수동 설정)에 따라 UI 전체를 한국어/영어로 전환. 향후 추가 언어 확장 가능한 구조.

---

## 1. 아키텍처

### 파일 구조

```
js/
  locales/
    ko.js        ← 한국어 문자열 (기존 i18n.js에서 이동)
    en.js        ← 영어 번역
  utils/
    i18n.js      ← 완전 재작성: t(), setLocale(), getLocale(), initLocale()
```

### i18n.js 핵심 API

```js
// 앱 시작 시 한 번 호출 (IndexedDB에서 저장된 언어 불러옴)
await initLocale()

// 언어 감지 우선순위: IndexedDB 설정 → navigator.language → 'ko' 폴백
detectLocale()

// 현재 언어 코드 반환
getLocale()  // → 'ko' | 'en' | ...

// 언어 변경 + IndexedDB 저장 + 페이지 re-render
await setLocale('en')

// 번역 함수 (동기) — 없는 키면 키 자체 반환 (안전한 폴백)
t('dashboard.title')
t('contracts.daysLeft', { n: 3 })  // 템플릿 변수 치환 지원
```

### 로케일 파일 구조

```js
// ko.js / en.js 공통 구조
export default {
  nav:       { home, groups, calendar, stats, settings },
  dashboard: { title, subtitle, ... },
  groups:    { title, addGroup, editGroup, deleteGroup, ... },
  attendance:{ title, checkAttendance, ... },
  status:    { present, absent, late, early, none },
  date:      { today, yesterday, daysLeft, ... },
  settings:  { title, account, language, ... },
  messages:  { groupCreated, saveFailed, nameRequired, ... },
  placeholders: { groupName, studentName, ... },
  // ...
}
```

## 2. 언어 감지 및 초기화

- `initLocale()` — 앱 시작 시 `app.js`에서 호출
  1. IndexedDB `settings` 스토어에서 `{ key: 'locale' }` 읽기
  2. 없으면 `navigator.language` 로 감지 (`'en-US'` → `'en'`, `'ko-KR'` → `'ko'`)
  3. 지원하지 않는 언어면 `'ko'` 폴백
  4. 해당 로케일 파일 import 후 메모리에 캐시

- 지원 언어 목록 `SUPPORTED_LOCALES = ['ko', 'en']` 상수로 관리

---

## 3. 언어 설정 UI

설정 페이지에 "언어" 카드 추가:

```
언어
  ○ 시스템 언어 사용  (기본값 — navigator.language 기반)
  ○ 한국어
  ○ English
```

- 라디오 버튼 UI, 변경 즉시 적용 (저장 버튼 없음)
- 선택 즉시 `setLocale()` 호출 → IndexedDB 저장 → `window.dispatchEvent(new Event('localechange'))` → 앱 전체 re-render
- "시스템 언어 사용" 선택 시 IndexedDB에서 `locale` 키 삭제 (= 자동 감지 상태로 복귀)

## 4. 날짜 포맷 다국어화

`date.js`의 한국어 전용 함수들을 locale-aware 버전으로 확장:

| 기존 함수 | 변경 후 |
|----------|--------|
| `formatDateKo(str)` | `formatDate(str, locale)` |
| `formatYearMonthKo(str)` | `formatYearMonth(str, locale)` |
| `relativeDateLabel(str)` | `relativeDateLabel(str, locale)` |
| `daysToNextClass(...)` | 요일 계산 로직 locale 독립적으로 유지 (내부 배열만 변경) |

영어 포맷 예시:
- `"2024-03-15"` → `"March 15, 2024 (Fri)"`
- `"2024-03"` → `"March 2024"`
- 오늘 → `"Today"`, 어제 → `"Yesterday"`

## 6. 확장성

- 새 언어 추가 시: `js/locales/ja.js` 파일 생성 + `SUPPORTED_LOCALES`에 추가만 하면 됨
- 번역 누락 키는 키 이름 자체를 표시 (조용한 폴백, 에러 없음)
- 추후 필요 시 ko → en 폴백 체인 추가 가능
