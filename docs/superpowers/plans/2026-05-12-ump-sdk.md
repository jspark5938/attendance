# UMP SDK 적용 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AdMob 광고 표시 전 Google UMP SDK를 통해 GDPR/CCPA 동의를 수집하고, Settings 페이지에서 사용자가 동의를 재설정할 수 있도록 한다.

**Architecture:** `ads.js`의 `_initAdMob()` 호출 앞에 `_requestConsent()` 단계를 삽입한다. 동의 결과(`canRequestAds`)가 true일 때만 배너를 표시한다. 마지막 동의 정보를 `_lastConsentInfo`에 캐시하여 Settings 페이지가 재호출 없이 상태를 읽을 수 있게 한다.

**Tech Stack:** `@capacitor-community/admob` v8 (UMP API 내장), Capacitor 8, Vanilla JS (ES Modules)

### Task 2: ads.js — UMP 동의 흐름 추가

현재 `init()` 흐름:
```

```

- [ ] **Step 1: 상수 수정 및 캐시 필드 추가**

파일 상단의 기존 상수 블록을 아래와 같이 교체한다.

`USE_TEST_ADS` 위의 줄부터 `isAndroid` 선언까지:

```js
// Google 공식 테스트 광고 ID (항상 테스트 광고 표시)
const TEST_BANNER_ID = 'ca-app-pub-3940256099942544/6300978111';

// 실제 광고 ID
const REAL_BANNER_ID = 'ca-app-pub-1007656354860622/8325774890';

// true = 테스트 광고, false = 실제 광고
const USE_TEST_ADS = false;

// UMP 디버그 지역 설정
// 0 = 실제 지역 기반 (배포용)
// 1 = EEA 강제 (GDPR 테스트)
// 3 = 미국 규제 주 강제 (CCPA 테스트)
const DEBUG_GEOGRAPHY = 1;

// 배너 로드 실패 시 최대 재시도 횟수 및 대기 시간
```

- [ ] **Step 2: `init()` 메서드 수정**

기존 `_initAdMob()` 직접 호출을 `_requestConsent()` 경유로 변경:

```js

      this.hide();
      return;
```

- [ ] **Step 3: `_initAdMobWithConsent()` 메서드 추가**

`_initAdMob()` 메서드 바로 위에 추가:

```js
  /** UMP 동의 획득 후 광고를 초기화하는 진입점 */
  async _initAdMobWithConsent() {
    try {
      const AdMob = window.Capacitor?.Plugins?.AdMob;
      if (!AdMob) return;

      const canRequestAds = await this._requestConsent(AdMob);
      if (!canRequestAds) {
        console.warn('[AdsService] canRequestAds=false, skipping banner.');
        return;
      }

      await this._initAdMob();
    } catch (e) {
      console.warn('[AdsService] consent/init failed:', e);
    }
  },
```

- [ ] **Step 4: `_requestConsent()` 메서드 추가**

`_initAdMobWithConsent()` 바로 아래에 추가:

```js
  /**
   * UMP 동의 요청.
   * 동의 폼이 필요하면 표시하고, 광고 요청 가능 여부(canRequestAds)를 반환.
   */
  async _requestConsent(AdMob) {
    const info = await AdMob.requestConsentInfo({
      debugGeography: DEBUG_GEOGRAPHY,
    });
    this._lastConsentInfo = info;

    if (info.isConsentFormAvailable && info.status === 'REQUIRED') {
      const updated = await AdMob.showConsentForm();
      this._lastConsentInfo = updated;
      return updated.canRequestAds;
    }

    return info.canRequestAds;
  },
```

- [ ] **Step 5: `showPrivacyOptions()` 공개 메서드 추가**

`show()` 메서드 바로 아래에 추가:

```js
  /** Settings 페이지에서 사용자가 동의를 재설정할 때 호출 */
  async showPrivacyOptions() {
    try {
      const AdMob = window.Capacitor?.Plugins?.AdMob;
      if (!AdMob) return;
      await AdMob.showPrivacyOptionsForm();
    } catch (e) {
      console.warn('[AdsService] showPrivacyOptionsForm failed:', e);
    }
  },

  /** 마지막으로 캐시된 동의 정보의 privacyOptionsRequirementStatus 반환 */
  getPrivacyOptionsStatus() {
    return this._lastConsentInfo?.privacyOptionsRequirementStatus ?? null;
  },
```

- [ ] **Step 6: `_initAdMob()` 내부 AdMob 취득 코드 제거**

기존 `_initAdMob()`은 내부에서 `AdMob`을 직접 취득했으나, 이제 `_initAdMobWithConsent()`에서 이미 검증된 `AdMob` 인스턴스를 사용하도록 변경:

```js
  /** AdMob: initialize banner via Capacitor plugin */
  async _initAdMob() {
    try {
      const AdMob = window.Capacitor?.Plugins?.AdMob;
      if (!AdMob) return;

      await AdMob.initialize({
        requestTrackingAuthorization: false,
        initializeForTesting: USE_TEST_ADS,
      });

      await this._showBannerWithRetry(AdMob, 0);
    } catch (e) {
      console.warn('[AdsService] AdMob init failed:', e);
    }
  },
```

> 이 메서드는 현재와 동일하게 유지한다 (이미 guard가 있으므로). 변경 불필요.
